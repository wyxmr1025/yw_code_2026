

```
kvm vmware xen 虚拟化技术  有自己独立内核

docker containerd podman 容器化技术  共享宿主机内核

​	很少使用单个docker服务器来管理容器，而是做成集群，通过k8s来做容器化编排。k8s 1.22 版本使用的容器默认docker  采用通用cri接口

​		容器就是用户空间虚拟化技术（独立网路，独立文件系统，独立主机名。。。。） + cgroup（资源限制，主要限制cpu和内存的大小）
​		约定俗成：一个容器必要有一个容器进程运行前台（一般情况一个容器只运行一个进程） 

docker框架： 在宿主机上面跑容器必须有一个启动容器的服务docker-engine引擎（管理容器的），管理容器就是要安装客户端命令： 就是一个docker命令，然后调用docker-engine引擎，在创建一个一个容器，把它做成磁盘文件我们把它叫做磁盘镜像文件，启动一个容器我们就启动那个镜像容器，镜像容器放在镜像仓库里面（里面有nginx的镜像等）。运行一个容器，docker就在本地查看有没有这个镜像，如果没有就在镜像仓库里面拉取下来，再将这个镜像运行成容器。
```

综上所述docker架构：需要有个docker服务端命令 + docker-engine + 镜像仓库



容器管理  		

阿里云搜索： docker-ce   7server--x86_64---stable（稳定版）---repodate----在linux上面添加仓库

--yum install docker-ce---启动docker  ----》systemctl start docker，要跑容器就需要镜像，公共镜像仓库：dockerhub。

	1、创建容器 
			docker run  镜像名:tag  [自定义指令] 
									-d  容器运行在后台 
									-p  暴露容器端口至宿主机
									--name ：指定容器名称
									--rm ：容器挂掉自动删除
									-it  交互式登录到容器  bin/sh
									-v ：挂载
	2、查询  
		docker  ps 
					-a  所有的容器处于exited
					inspect +id ：查询进程更详细的指令
	3、停止|kill 
	​	
			docker  stop|kill|start|restart|rm
			docker rm -f 强制删除
	
	docker  cp 实现文件传输
	
	docker  commit  将容器保存一个镜像


​	
​
