	lvs 调度模型：
	
	nat 模型   请求报文 响应报文 都要经过调度器
	
	dr  模型   请求报文经过调度器，响应报文不经过调度器
	
	tun 模型（隧道模型）

#### nat模型：


	调度算法  
		rr: roundrobbin  轮询
		lc： least connection  最少连接数
		wrr：加权轮询
		wlc ： 加权最少连接  连接数/权重=值（越少交给谁） 
		nq
		sh  source hash  源地址哈希   （临时解决会话不一致）
	http协议是无状态协议的每次请求都是没有关系的，不会保存登陆状态
	cookie：会员卡
	session：保存的身份信息（redis来做session服务器）



237.136（调度器）

```
yum install ipvsadm -y ---ipvsadm调度器工具
curl 192.168.66.120
curl 192.168.66.130
-A： 添加一个服务
-t： 添加tcp协议
-s： 轮询调度算法
-m：采用的模型（-m指定采用nat模型，默认采用dr模型）
添加服务：ipvsadm -A -t 192.168.227.136:8090 -s rr  ===开店
ipvsadm -a -t 192.168.227.136:8090 -r 192.168.237.51:80 -m  ===店员
ipvsadm -a -t 192.168.227.136:8090 -r 192.168.237.52:8080 -m  ====店员
ipvsadm -L -n ===>查看调度规则
开启转发功能： echo 1 > /proc/sys/net/ip_forward
在浏览器中写上192.168.66.110：8090====》轮询

健康监测脚本：，如果两台web服务器都下线了由调度器提供服务
#!/bin/bash
rs=(192.168.66.120:80 192.168.66.130:80) ===数组
vip=192.168.227.136
vport=8090
while true ;do
for r in ${rs[@]}; do
	if curl $r &> /dev/null; then
        if ! ipvsadm -L -n |grep $r &> /dev/null ; then
                ipvsadm -a -t  $vip:$vport -r $r -m
        fi
	else
        if ipvsadm -L -n |grep $r &> /dev/null ; then
                ipvsadm -d -t  $vip:$vport -r $r
        fi
	fi
done
sleep 2
done
```
